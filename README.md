# Cinema-Booking-System

## Project Overview

The Cinema Booking System is an academic software development project designed to manage cinema operations and simplify the movie ticket booking process.

The system provides different functionalities for cinema managers, ticketing clerks and customers. It allows users to manage movies, showtimes, bookings and customer information through a graphical user interface.

## Technologies Used

- JavaScript
- Text File Storage

## User Roles and Features

### 1. Main

- Provides access to the different system modules.
- Allows users to navigate to their respective sections.

### 2. Cinema Manager

- Manage movie information.
- Manage movie showtimes.
- Manage cinema halls and seat layouts.
- Manage cinema-related information.

### 3. Ticketing Clerk

- Create and manage ticket bookings.
- Search, modify and cancel bookings.
- Process ticket payments.
- Generate and view booking receipts.

### 4. Customer

- Browse available and upcoming movies.
- View movie details and showtimes.
- Select movie dates and seats.
- Make ticket bookings and payments.
- View booking history.
- Manage customer points.

## Data Storage

The system uses text files to store and manage application data.
